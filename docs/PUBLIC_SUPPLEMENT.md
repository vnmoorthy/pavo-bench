The public, de-anonymized camera-ready supplement for PAVO is intended to be
attached to the GitHub `v1.0.1` release as:

`PAVO_TMLR_camera_ready_supplementary_deanonymized.zip`

Planned release URL (not live until the `v1.0.1` release and asset are
published):

`https://github.com/vnmoorthy/pavo-bench/releases/download/v1.0.1/PAVO_TMLR_camera_ready_supplementary_deanonymized.zip`

SHA-256:

```text
3cb19f33967213c285941872f6dfd776170ac7a7feecacc6a28cfbeb08ac581a
```

Verify a downloaded copy with:

```bash
shasum -a 256 PAVO_TMLR_camera_ready_supplementary_deanonymized.zip
```

This is the public bundle containing de-anonymized authorship and citation
metadata. The separate anonymous TMLR-upload supplement is intentionally not a
public release asset and must not be substituted for this file.
